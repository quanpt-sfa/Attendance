DATABASE DESIGN DOCUMENTATION
Database File: attendance.db
Type: SQLite

TABLE: classes
- class_id (TEXT, PRIMARY KEY): Unique identifier for the class (Subject Code)
- credit_class_id (TEXT): Credit class identifier
- class_name (TEXT): Name of the class
- start_date (TEXT): Start date of the course (YYYY-MM-DD)
- num_sessions (INTEGER): Total number of sessions (default: 10)
- session_interval (INTEGER): Days between sessions (default: 7)
- default_start_period (INTEGER): Default starting period (1-12)
- default_end_period (INTEGER): Default ending period (1-12)
- room (TEXT): Classroom location
- created_at (TEXT): Timestamp of creation
- updated_at (TEXT): Timestamp of last update

TABLE: sessions
- session_id (INTEGER, PRIMARY KEY AUTOINCREMENT): Unique session ID
- class_id (TEXT, FOREIGN KEY references classes.class_id): The class this session belongs to
- session_number (INTEGER): Sequence number of the session (1, 2, 3...)
- session_date (TEXT): Date of the session (YYYY-MM-DD)
- start_period (INTEGER): Starting period of the session
- end_period (INTEGER): Ending period of the session
- is_open (INTEGER): Status (1: Open for seeking, 0: Closed)
- opened_at (TEXT): Timestamp when attendance was opened
- closed_at (TEXT): Timestamp when attendance was closed

TABLE: students
- student_id (TEXT): Student ID (MSSV)
- class_id (TEXT): Class ID this student record belongs to
- last_name (TEXT): Student's last name
- first_name (TEXT): Student's first name
- full_name (TEXT): Full name
- email (TEXT): Student's email
- birth_date (TEXT): Date of birth
- gender (TEXT): Gender
- photo_path (TEXT): Path to student's photo (relative to photos/ dir)
- card_uid (TEXT): RFID/NFC Card UID associated with the student
- card_registered_at (TEXT): Timestamp when the card was registered
- created_at (TEXT): Record creation timestamp
* PRIMARY KEY (student_id, class_id) - A student is unique within a class context

TABLE: checkins
- id (INTEGER, PRIMARY KEY AUTOINCREMENT): Unique Check-in record ID
- session_id (INTEGER, FOREIGN KEY references sessions.session_id): The session checked in
- student_id (TEXT): Student ID
- class_id (TEXT): Class ID
- check_type (TEXT): Type of check-in ('in' or 'out')
- check_time (TEXT): Time of check-in (HH:MM:SS DD/MM/YYYY)
- bonus_points (INTEGER): Bonus points awarded (default 0)
- bonus_reason (TEXT): Reason for bonus points
* UNIQUE(session_id, student_id, check_type) - One check-in per type per session

TABLE: absences
- id (INTEGER, PRIMARY KEY AUTOINCREMENT): Unique absence record ID
- session_id (INTEGER, FOREIGN KEY references sessions.session_id): The session missed
- student_id (TEXT): Student ID
- class_id (TEXT): Class ID
- reason (TEXT): Reason for absence
- created_at (TEXT): Timestamp
* UNIQUE(session_id, student_id)

TABLE: logs
- id (INTEGER, PRIMARY KEY AUTOINCREMENT): Log ID
- time (TEXT): Log timestamp
- session_id (INTEGER): Related session ID
- class_id (TEXT): Related class ID
- student_id (TEXT): Related student ID
- check_type (TEXT): Check type if applicable
- result (TEXT): Result of the operation
- note (TEXT): Additional notes
